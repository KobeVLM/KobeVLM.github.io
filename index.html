Structure before style

The most community-praised free full stack curriculum. Starts with HTML/CSS, uses real dev tools (VS Code, Git, terminal) from day one. No hand-holding, which is good.

CSS — Learn by Playing

Layouts, flexbox, grid
MOST FUN PHASE
🎮 Do the games first before reading anything. They take 2–3 hours total and you'll understand Flexbox and Grid better than most devs who read docs for days.
🐸
Flexbox Froggy
Move frogs to lily pads using CSS Flexbox properties. 24 levels. Sounds dumb, actually one of the best ways to internalize Flexbox alignment and direction.
FREE GAME
🥕
CSS Grid Garden
Same concept as Froggy but for CSS Grid. 28 levels covering grid-column, grid-row, grid-area, and more. Do this right after Froggy.
FREE GAME
🍽️
CSS Diner
32 levels of CSS selector challenges set in a restaurant. Covers basic to advanced selectors. Extremely useful for React/Next.js styled components later.
FREE GAME
▶️
Kevin Powell — YouTube
Widely regarded as the best CSS teacher on the internet. Explains why things work, not just how. Watch topic-by-topic as you encounter things you don't understand. "Responsive CSS" and "CSS Variables" playlists are must-watches.
FREE VIDEO
⚔️
The Odin Project — CSS Foundations
Continue from Phase 1. The CSS section has you build real projects: a landing page, a recipe site, a calculator. This is where it clicks.
FREE Project-based

JavaScript Deep Dive

Before React, this must be solid
CRITICAL
⚠️ Most people rush to React with weak JS fundamentals and suffer later. Spend real time here. Focus on: DOM manipulation, array methods, async/await, fetch, and ES6+ features.
📘
javascript.info — The Modern JS Tutorial
The most recommended free JS learning resource on the internet. Covers everything from basics to advanced topics like closures, prototypes, async, and the browser API. Extremely well-written with exercises.

12-hour free JavaScript course on YouTube. Great supplementary visual resource to use alongside javascript.info. Bro Code's teaching style is fast, clear, and no-fluff.
FREE VIDEO
⚔️
The Odin Project — JavaScript
Continues the Odin path into advanced JavaScript: OOP, testing, async, data structures and algorithms basics. Projects include a weather app, a library, a battleship game.

04

TypeScript

JS with superpowers
HIGH ROI
💡 You already use TS in PAMANA and Flashcard Frenzy. This phase is about going from "it compiles so I'm fine" to actually understanding the type system — generics, unions, type guards, and utility types.
🔷
Total TypeScript — Free Tutorials
By Matt Pocock — widely considered the best TS educator. His free tutorials cover Beginner's TypeScript, TypeScript Errors, and React with TypeScript. Hands-on in your editor with real exercises.
FREE Community #1 for TS
📖
TypeScript Official Handbook
Use this as a reference when Total TypeScript doesn't cover something specific. The "Everyday Types" and "Generics" sections are the most important to read top to bottom.
FREE Reference

🧠 The Rule That Changes Everything

For every phase, the pattern is: read/watch just enough to start, then build something with it immediately. Don't finish an entire course before coding. The mistake most students make is consuming 40 hours of content with 2 hours of actual building. Flip that ratio. After each section of Odin Project or any tutorial, close the tab and rebuild what you just learned from scratch without looking. That's when it actually sticks. And every project you build — no matter how small — goes on GitHub with a proper README.
