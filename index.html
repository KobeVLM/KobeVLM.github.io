tar — Archive & Compress

Bundle files into a tarball, compress with gzip, move, verify, and inspect — all without extracting.

// flags
-c
Create a new archive
-v
Verbose — print filenames to screen
-z
Compress / decompress using gzip
-t
List contents without extracting
-f
Specify the archive filename (always last before the name)
-x
Extract files from an archive
// command flow
1 · Create & Compress
tar -cvzf archive.tar.gz /path/to/source
Combines -c (create) -v (verbose) -z (gzip) -f (filename). The output file comes right after -f.
2 · Move the File
mv archive.tar.gz /destination/
3 · Verify File & Size
ls -lh /destination/
-l = long format, -h = human-readable sizes (KB/MB)
4 · Inspect Contents Safely (no extract)
tar -tzvf /destination/archive.tar.gz
-t lists contents. Safe: never touches/extracts any file.

chmod & chown — Permissions & Ownership

Control who can read, write, and execute files. Assign ownership to users and groups.

// permission values
SymbolValueMeaning
r4Read
w2Write
x1Execute
—0No permission
// common permission numbers
NumberOwnerGroupOthersUse case
755rwxr-xr-xPublic scripts / executables
750rwxr-x---Group-accessible dirs
644rw-r--r--Normal files
600rw-------Private files (SSH keys)
// command flow
Change Owner & Group
chown owner:group file.txt
Colon separates user and group. Either side can be omitted to change just one.
Recursive Ownership
chown -R owner:group /dir/
-R applies to all files and subdirectories inside.
Set Standard Permission
chmod 755 /opt/app/script.sh
7=rwx (owner), 5=r-x (group), 5=r-x (others)
Recursive Permission Change
chmod -R 750 /opt/data/
Others get zero access. Group can read and execute.

ACL — Access Control Lists

Grant fine-grained access to specific users or groups beyond standard owner/group/others model.

// setfacl flags
-m
Modify — add or update an ACL rule
-x
Remove a specific user/group ACL entry
-R
Recursive — apply to all files in a directory
-b
Remove all ACLs — revert to standard permissions
// acl rule format
Format
u:username:rwx  |  g:groupname:rw
u = user, g = group. Permissions follow the same r/w/x letters.
// command flow
Check Current ACL
getfacl /opt/data/file.txt
Grant User Access
setfacl -m u:bob:rw /opt/data/file.txt
bob gets read+write even if he's not the owner.
Grant Group Access
setfacl -m g:devs:rw /opt/data/
Recursive Apply (incl. new files)
setfacl -Rm u:bob:rwx /opt/data/
Remove an Entry
setfacl -x u:bob /opt/data/file.txt
No permission string needed — just identify the user/group to remove.

sed — Stream Editor

Find and replace text in files, delete lines, and pipe transformations — all non-interactively.

// anatomy of a sed command
Full Structure
sed -i 's/OldWord/NewWord/g' file.txt
What each part means
-i  → in-place (edit file directly)
s   → substitute mode
/Old/ → pattern to find
/New/ → replacement text
g   → global (all matches on each line)
gI  → global + case-insensitive
// command flow
Global In-Place Swap
sed -i 's/OldWord/NewWord/g' file.txt
Replaces every occurrence of OldWord. Modifies the file directly.
Case-Insensitive Swap
sed -i 's/OldWord/NewWord/gI' file.txt
Matches "oldword", "OldWord", "OLDWORD", etc.
Delete Lines Containing a Word → New File
sed '/word/d' /home/BSD.txt > /home/BSD_DELETE.txt
No -i here — output is redirected. Original file untouched.
Validate the Swap
grep 'OldWord' file.txt  # should return nothing
grep 'NewWord' file.txt  # should show results

scp — Secure Copy (SSH-based)

Transfer files and directories between local and remote systems over an encrypted SSH connection.

// flags
-r
Recursive — copy entire directories
-P
Port — specify non-standard SSH port (capital P)
// scp syntax pattern
Remote Path Format
user@host:/remote/path/file.txt
The colon (:) separates the host from the remote path.
// command flow
Upload: Local → Remote
scp /local/file.txt user@host:/remote/dest/
Source first, destination second — same as cp.
Download: Remote → Local
scp user@host:/remote/file.txt /local/dest/
Recursive Directory Push
scp -r /local/dir/ user@host:/remote/path
Non-Standard Port
scp -P 2222 user@host:/path/file.txt local/
Capital -P for scp. (ssh uses lowercase -p — a common trick question!)

cron — Job Scheduling & Access Control

Schedule recurring tasks. Restrict or allow specific users from running cron jobs.

// cron access control files
/etc/cron.deny
/etc/cron.deny
Users listed here are BLOCKED from using cron. Everyone else can use it by default.
/etc/cron.allow
/etc/cron.allow
If this file exists, ONLY users listed here can use cron. Acts as a whitelist. More restrictive.
// crontab time format
Format
*  *  *  *  *  /command/to/run
│  │  │  │  │
min hr dom mon dow
dom=day of month, dow=day of week (0=Sun). * means "every".
// command flow
Block a User (add to deny list)
echo 'Jerome' >> /etc/cron.deny
>> appends without overwriting. Jerome can no longer use crontab.
Whitelist a User (exclusive allow)
echo 'siva' >> /etc/cron.allow
If cron.allow exists, only listed users can schedule jobs.
Restart the Cron Daemon
systemctl restart crond
Apply changes. On some distros the service is called "cron" not "crond".
Other useful crontab commands
crontab -e  # edit your crontab
crontab -l  # list current crontab
crontab -r  # remove all cron jobs
